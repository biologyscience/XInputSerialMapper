## 🛠️ Install the app
Before installing the project, make sure you have the following installed on your PC
- [npm](https://www.npmjs.com/) & [Node.js](https://nodejs.org) latest LTS version
- [ViGEmBus](https://github.com/nefarius/ViGEmBus)

## 💠 Download the projeect
Check out the [Releases](https://github.com/biologyscience/XInputSerialMapper/releases) and download the project files (.zip)

**OR**

Clone this repository by using [git](https://git-scm.com/)
```
git clone https://github.com/biologyscience/XInputSerialMapper.git
```
go into the project folder and install the dependencies using [npm](https://www.npmjs.com/)
```
cd XInputSerialMapper
npm install
```
